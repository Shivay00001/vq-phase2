# VQ Phase-2 Foundations

Foundation slices for VisionQuantech's Phase-2 platform: VisionOS, VisionCloud,
VisionID, VisionERP. Each module ships research docs (PRD/TRD) plus a working
slice. These are **prototypes, not production systems** — each module README
documents honestly what's real vs. what's a UX concept.

## Modules

- `vision-os/` — OS layer: U-PERM capability library (29/29 tests pass),
  web-shell UX concept prototype.
- `vision-cloud/` — S3-style object storage running on local disk.
- `vision-id/` — auth/identity slice.
- `vision-erp/` — CRM + HRMS + billing slice.

See each module's README for its real-vs-prototype breakdown.
